Copy this folder to `src/content/projects/<slug>/`. The folder name becomes the URL,
so `src/content/projects/varibl/` is published at `/projects/varibl/`. Drop the cover
image in the same folder and point `image` at it with a `./` path. Any aspect ratio
works; the list crops it to 16:9 and the project page shows it whole.

Everything below the frontmatter is the write-up. It can be short or a full README.
