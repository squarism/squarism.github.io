Copy this folder to `src/content/features/<slug>/`. The folder name becomes the URL,
so `src/content/features/downtime/` is published at `/features/downtime/`.

Images are relative to the folder you copy.

Features are MDX, so a feature can import and place components. Interactive pieces
live in `src/features/<name>/` as Vue components. Give the component's root element
the `feature-wide` class and it breaks out to the full page width; everything else
stays at article width.

```mdx
import Downtime from "@/features/downtime/Downtime.vue";

<Downtime client:visible level={1} />
```
